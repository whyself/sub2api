# Qoder 运行源码快照

此目录保存服务器当前 Qoder 转换程序及其测试源码，作为原生支持商开发的起点。

这份提交完成源码追踪，不代表已经实现 sub2api 内置的 Qoder OAuth 支持商。原生接入计划见 `docs/QODER_PROVIDER_PLAN_CN.md`。

## 凭证与配置

运行数据目录通过 `--data` 参数指定。登录令牌、续期令牌、密钥及授权中的临时状态均应保存在仓库之外。

不要将现有运行数据复制到此目录。

## 现有能力

- 国内版设备授权与 PKCE。
- 动态查询模型目录。
- 生成 COSY 认证头并编码聊天正文。
- 聊天补全、流式响应及函数工具调用。

源码快照应与实际部署分别记录；修改并提交源码不会自动替换服务器的运行程序。
